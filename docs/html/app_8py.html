◆ crear_alumno()

app.crear_alumno ( )

Crea un alumno a partir del cuerpo JSON de la solicitud.

El nombre debe ser un texto no vacío y el promedio un número entre 1 y 7. La carrera es opcional. Los datos se conservan solo mientras vive el proceso.

Returns
Alumno creado con código 201 o error de validación con código 400.
